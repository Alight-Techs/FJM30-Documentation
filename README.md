# FJM30 SDR SoC

## RF + FPGA + ARM Integrated SDR System-in-Package

FJM30 is a highly integrated SDR SoC based on System-in-Package (SiP) technology, combining RF transceiver, FPGA programmable logic, ARM processors and memory into a compact 17×17 mm BGA package.

## Key Features

- RF Frequency Range: 50 MHz – 6 GHz
- 2T2R SDR Architecture
- FPGA Programmable Logic
- Dual-Core ARM Processing System
- Integrated Memory
- Compact 17×17 mm BGA Package
- Simplified SDR Hardware Architecture
